# 需求文档

## 简介

为 wiliwili 应用添加本地视频播放功能，允许用户通过主界面的图标按钮播放本地视频文件（如 network.mp4）。

## 术语表

- **wiliwili**: 一个基于 borealis 框架的视频播放应用
- **Intent**: 应用中用于打开不同页面和功能的辅助类
- **MainActivity**: 应用的主界面活动
- **MPVCore**: 视频播放核心组件
- **本地视频**: 存储在应用资源目录中的视频文件

## 需求

### 需求 1

**用户故事:** 作为用户，我想要在主界面点击一个图标按钮，以便播放本地视频文件

#### 验收标准

1. WHEN 用户在主界面看到图标按钮 THEN 系统应显示一个可点击的视频播放图标
2. WHEN 用户点击该图标按钮 THEN 系统应打开视频播放器并播放指定的本地视频文件
3. WHEN 系统播放本地视频 THEN 系统应使用 MPV 播放器核心加载 resources/pictures/network.mp4 文件
4. WHEN 视频播放器打开 THEN 系统应提供标准的播放控制功能（播放、暂停、进度条等）

### 需求 2

**用户故事:** 作为开发者，我想要扩展 Intent 类，以便支持打开本地视频文件

#### 验收标准

1. WHEN Intent 类添加新方法 THEN 系统应提供 openLocalVideo 静态方法接受文件路径参数
2. WHEN openLocalVideo 被调用 THEN 系统应创建并推送一个播放器活动到应用栈
3. WHEN 播放器活动被创建 THEN 系统应正确初始化 MPV 核心以播放本地文件

### 需求 3

**用户故事:** 作为用户，我想要图标按钮与其他主界面按钮保持一致的样式，以便获得统一的用户体验

#### 验收标准

1. WHEN 图标按钮被渲染 THEN 系统应使用与设置按钮和收件箱按钮相同的样式
2. WHEN 图标按钮获得焦点 THEN 系统应显示激活状态的图标
3. WHEN 图标按钮失去焦点 THEN 系统应显示普通状态的图标
4. WHEN 用户使用触摸或手柄导航 THEN 系统应支持点击和手柄按钮操作

### 需求 4

**用户故事:** 作为用户，我想要在退出本地视频播放器时应用保持稳定，以便不会遇到崩溃或错误

#### 验收标准

1. WHEN 用户按返回键退出播放器 THEN 系统应正确停止视频播放并释放资源
2. WHEN 播放器活动被销毁 THEN 系统应在销毁 VideoView 前停止 MPV 播放器核心
3. WHEN 资源清理过程执行 THEN 系统应按正确顺序释放资源以防止崩溃
4. WHEN 播放器退出 THEN 系统应取消所有 MPV 事件订阅
5. WHEN 播放器退出后 THEN 系统应返回主界面且应用保持稳定运行
